# myco-phylo

Collection of scripts and workflows for fungal (meta)barcoding data, genome assembly, and phylogenetics/genomics with a focus on old specimens and systematics. Used for material produced in [FunDive WP1](https://fun-dive.eu/en/communication/) (fungal types) and in projects of Otto Miettinen: University of Helsinki 3-year research grant 2017-2020, Academy of Finland project grant 315927 (2018-2022). Initially built for Puhti cluster and later adapted for LUMI.
